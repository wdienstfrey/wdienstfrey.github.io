# Will Dienstfrey research website

Static site for free GitHub Pages hosting.

## Publish
Create a public repository named `wdienstfrey.github.io`, upload the contents of this folder to the repository root, then enable GitHub Pages under Settings -> Pages -> Deploy from a branch -> main -> / (root).

## Project photos
Replace `assets/project-1.svg` through `assets/project-5.svg` with your own JPG/PNG files and update the matching filenames in `index.html` and `projects.html`.

## Photos page
Replace the six `photo-#.svg` placeholders and edit captions in `photos.html`.

The background image, profile photo, and CV are already included.


## Current project images
The four project images supplied by Will are installed as `assets/project-1.jpg` through `assets/project-4.jpg`, in project-page order. The Yellowstone project is not displayed in this version.
